# Contracts registry

Canonical, machine-readable contracts for AegisShield AI. Every file has exactly one owner and one reviewer. Version for all files: **1.0.0** (frozen Sun 25 Oct 2026; see change rules in `docs/00-source-of-truth.md` §15).

Run before every merge:

```bash
pip install "jsonschema>=4.18" pyyaml openapi-spec-validator
python3 tools/check_contracts.py
```

## Conventions (summary of `docs/00` §9.1)
- JSON Schema draft 2020-12; schemas reference each other by **relative file name** (no `$id`), so tooling resolves them from disk.
- Money: integer whole rupees (`*_inr`); rates in basis points (`*_bps`); rounding half-up per line.
- Dates `YYYY-MM-DD` (Asia/Kolkata business dates); timestamps RFC 3339 with offset; `effective_to` inclusive.
- Nullable fields are always present; empty lists are `[]`.
- Every payload carries `schema_version`.
- Golden comparisons ignore these keys anywhere: `created_at`, `updated_at`, `started_at`, `finished_at`, `completed_at`, `decided_at`, `occurred_at`, `duration_ms`, `generated_at`, `reset_at`, `prev_hash`, `event_hash`.
- `plan_hash` covers exactly `plan_hash_material` (described in `plan.schema.json#/$defs/RecoveryPlan`); `input_snapshot_id` is the SHA-256 of the canonical JSON of all twelve fixture files keyed by file stem.

## Changing a contract
1. Edit schema + examples + fixtures + `CHANGELOG.md` in one pull request.
2. If behaviour changed, Member 3 regenerates goldens with `--write-golden`; the reviewer checks the diff line by line.
3. Checker green; reviewer approves; consumers tagged.
4. Major changes, or any change after D5, need Member 5's entry in the decision log (`docs/05` §9).

## Type generation hints
- Frontend: bundle first (`npx @redocly/cli bundle contracts/openapi.yaml -o build/openapi.bundled.yaml`), then `npx openapi-typescript build/openapi.bundled.yaml -o frontend/src/api/schema.d.ts`.
- Backend: `datamodel-codegen --input contracts/schemas --input-file-type jsonschema --output backend/app/models/generated --output-model-type pydantic_v2.BaseModel` (fall back to hand-written models validated in tests).
